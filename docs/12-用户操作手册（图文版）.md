## 0. 快速安装与启动（VS Code 一键启动）

### 0.1 环境要求
- Python 3.9+（本项目使用 3.9 兼容语法）
- Node.js 18+ 与 pnpm
- 浏览器（Chrome / Edge 最新版）

### 0.2 后端启动
```bash
cd backend
python -m venv .venv && .venv/Scripts/activate     # Windows（Git Bash 用 source .venv/Scripts/activate）
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
- 首次启动自动建库并幂等灌入演示数据（`backend/app/seed.py`）。
- 访问交互式接口文档：<http://127.0.0.1:8000/docs>（FastAPI Swagger UI）。

### 0.3 前端启动
```bash
cd frontend
pnpm install
pnpm dev     # 打开 http://127.0.0.1:5173
```

## 2. 协会管理中心（`/association`）

四大子页签：会员档案库 / 入会审核与转正 / 周期考核 / 组织任职与奖惩评优。

1. **入会审核**：进入「入会审核与转正」页签，对待审核申请点「审核」，通过后自动创建 `CANDIDATE` 备选会员（**BR-001**）。
2. **备选转正**：在会员档案库找到备选会员，点「转正」，指定竞赛/非竞赛方向（**BR-002**）。
3. **周期考核**：录入考核时，若「不合格」，系统自动流转状态：单次 → 观察，连续两次 → 待清退（**BR-003**）。

> 📷 截图 2-1：入会审核列表与「审核通过 → 备选会员」弹窗。

## 3. 算法题库管理（`/question-bank`）

1. **组合检索**：勾选多个「算法知识点（蓝）」/「实现能力标签（紫）」，切换「交集 AND / 并集 OR」（**BR-006**）。
2. **题目详情**：点击题目打开抽屉，查看题面、样例、题解；可「新增题解」。
3. **专题题单**：编排题单并绑定 `target_dimension`，供能力评估推荐与训练计划引用。

## 4. 个人能力评估（`/ability`）

1. 顶部选择「竞赛会员」。
2. 左侧展示**六维能力 SVG 雷达图**（蓝色最新 / 绿色上期对比），低于 70 分的维度标红。
3. 右侧「薄弱项自动识别清单」与「智能匹配补强题单」联动。
4. 点「+ 发起新一轮六维评估」录入六维分数，自动计算均分与薄弱项（**BR-005**）。

## 5. 训练与集训管理（`/training`）

三大子页签：训练计划 / 周任务打卡与考勤 / 寒暑假集训看板。

### 5.1 个人补强训练计划（BR-007）
1. 进入「训练计划」页签，点「+ 新建训练计划」。
2. 类型选择「个人补强计划」，选择面向的竞赛会员与关联题单。
3. 创建后，计划自动读取该会员**最近一次能力评估的薄弱项**并留存 `source_assessment_id` 快照。

### 5.2 周任务打卡与考勤
1. 进入「周任务打卡与考勤」，点「+ 下发训练任务」，关联训练计划与专题题单。
2. 任务列表展示补题进度条，点「打卡 / 记录考勤」填写考勤（正常/迟到/缺勤）与补题数量。

### 5.3 寒暑假集训看板
1. 进入「寒暑假集训看板」，点「+ 新建集训」创建寒假（WINTER）/暑假（SUMMER）集训。
2. 集训卡片可点「记录集训总结」，沉淀阶段复盘，衔接下一轮能力评估。

## 6. 队伍与竞赛管理（`/contest`）

三大子页签：队伍档案与能力互补 / 校赛晋级候补流转 / XCPC与非XCPC成绩归档。

### 6.1 能力互补组队（BR-005 / BR-008）
1. 点「✨ 生成能力互补候选组合」，系统基于最新六维能力画像推荐互补队伍。
2. 点「+ 组建队伍」选择队长与队员，留存入队能力快照。
3. 点「查看档案」查看「队员能力互补对比卡片」与「成员调整流水（Append-Only）」。

### 6.2 校赛晋级 / 候补递补（BR-009）
1. 顶部选择校赛，查看选手报名与初赛排名列表。
2. 对「晋级决赛」选手点「确认晋级参赛」或「放弃（触发候补递补）」。
3. 放弃/逾期时，系统按初赛排名升序自动从候补池递补首位选手并写日志。

### 6.3 异常行为人工复核（BR-010）
1. 在「线上初赛异常行为核查材料」区点「+ 登记核查材料」，仅留存证据链接与描述。
2. 材料状态固定为 `PENDING_REVIEW`，点「人工复核」填写复核人与三值结论（确认违规/排除嫌疑/证据不足）。

### 6.4 XCPC / 非XCPC 成绩归档（BR-008）
1. 「XCPC 队伍综合排序」表按排名展示队伍解题、罚时、赛站与奖项。
2. 「非 XCPC 赛事个人成绩」表登记蓝桥杯/天梯赛等个人制获奖记录。

## 7. 快速验收对照（BR-001 ~ BR-010）

| 业务规则 | 操作入口 | 预期结果 |
| :--- | :--- | :--- |
| BR-001 备选前置 | 协会管理 → 入会审核 | 审核通过仅进入 `CANDIDATE`，不可直接 `FORMAL` |
| BR-002 阶段/方向/职务分离 | 转正弹窗 + 组织任职 | 方向独立于职务，职务在 `org_positions` 维护 |
| BR-003 考核状态流转 | 周期考核录入 | 不合格 → 观察，连续两次 → 待清退 |
| BR-004 考核指标差异化 | 周期考核（竞赛/非竞赛） | 两类指标字段不同 |
| BR-005 能力评估独立 | 个人能力评估 | 六维画像 + 薄弱项（<70 分） |
| BR-006 题目多对多 | 题库组合检索 | AND/OR 组合命中 |
| BR-007 训练以评估为输入 | 训练计划（个人补强） | 自动读取薄弱项并留存评估快照 |
| BR-008 集训/XCPC 关联队伍 | 集训看板 + XCPC 成绩 | 队伍档案关联、成绩 Append-Only |
| BR-009 校赛候补递补 | 校赛晋级确认/放弃 | 放弃后同事务按排名递补候补 |
| BR-010 异常人工复核 | 校赛异常核查 | 仅留存材料，人工写三值结论 |
