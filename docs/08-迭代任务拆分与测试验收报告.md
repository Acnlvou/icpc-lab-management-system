## 三、核心业务验收用例与实测结论

> 测试框架：`pytest` + `FastAPI TestClient`（独立临时 SQLite 测试库，确保测试幂等无污染）

1. **会员生命周期闭环验收（BR-001 / BR-002）**：
   - 验证申请提交 → 审核通过自动生成 `CANDIDATE` 备选会员 → 入会考核转正为 `FORMAL` 并选择 `COMPETITION` 方向。
   - 验证非备选会员重复调用转正接口返回 `400 Bad Request`。
2. **周期考核自动状态流转验收（BR-003）**：
   - 首次录入考核不合格 → 会员状态由 `ACTIVE` 自动流转为 `OBSERVATION`（`consecutive_failures = 1`）。
   - 连续第二次录入考核不合格 → 自动流转为 `DISMISSAL_PENDING`（`consecutive_failures = 2`），并生成审计日志。
   - 考核通过后自动重置计数并恢复 `ACTIVE`。
3. **题库多对多标签组合检索验收（BR-006）**：
   - 创建同时绑定「动态规划（算法知识点）」与「边界处理（实现能力标签）」的题目。
   - 分别验证 `match_mode=all`（交集精准命中）与 `match_mode=any`（并集命中）及难度独立筛选结果准确。
4. **个人能力评估独立性与薄弱项诊断验收（BR-005）**：
   - 验证非竞赛会员发起个人能力评估被拒绝（`400`），保障评估与会员考核边界清晰。
   - 验证竞赛会员提交两次评估后，能够保留完整历史、自动标定 `< 70` 分薄弱维度，并匹配对应补强题单。
