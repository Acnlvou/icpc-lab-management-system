## 二、给后端负责人的接口与字段契约（最重要，请对齐）

> 前端全部经 `frontend/src/api/client.js` 访问 `/api/v1`，字段统一 `snake_case`。以下「入参」是前端 POST/PUT 时发送的 JSON，「出参」是前端渲染时读取的字段名。**请后端 Pydantic Schema 与响应字段严格按此命名**，否则页面有值也显示不出。

> **契约来源说明（重要）**：本节列出的**端点路径**来自 `.spec/api.spec.yaml`（已冻结的 Sprint 1~4 全量契约），但该文件每个端点只有一句 `summary`，**从未定义字段级 schema**；`docs/05-API接口规范.md` 也只覆盖到 v0.5.0（协会/题库/能力/看板），训练与竞赛域尚未写入。因此本节（以及 `docs/06` 第四节）是**首次把字段级契约落地成文**。若后端已按其他字段名实现，请以本节为准对齐（或先与我同步再定），避免联调对不上。

### 2.1 训练域（李靖宇负责，前缀 `/api/v1/training`）

| 方法 | 路径 | 入参（JSON body） | 查询参数 |
| :--- | :--- | :--- | :--- |
| GET | `/plans` | — | `plan_type`(OVERALL\|PERSONAL) |
| POST | `/plans` | `name, plan_type, member_id, cycle, problem_list_id, description` | — |
| GET | `/tasks` | — | 可选 `plan_id / member_id / status` |
| POST | `/tasks` | `title, plan_id, week, member_id, problem_list_id` | — |
| POST | `/tasks/{id}/checkin` | `attendance, solved_count, remark` | — |
| GET | `/camps` | — | `camp_type`(WINTER\|SUMMER) |
| POST | `/camps` | `name, camp_type, term, location, start_date, end_date` | — |
| POST | `/camps/{id}/summary` | `summary` | — |

**出参字段契约：**

- `TrainingPlan`：`id / name / plan_type(OVERALL|PERSONAL) / member_id / member_name / cycle / source_assessment_id / problem_list_id / problem_list_title / target_dimension / status / description / start_date / end_date`
- `TrainingTask`：`id / plan_id / plan_name / title / week / problem_list_id / problem_list_title / member_id / member_name / status(PENDING|IN_PROGRESS|DONE) / attendance(PRESENT|LATE|ABSENT) / solved_count / total_count / deadline / remark`
- `TrainingCamp`：`id / name / camp_type(WINTER|SUMMER) / term / team_id / team_name / location / start_date / end_date / status / summary`

> 关键业务约束（已写入 `.spec/rules.spec.md`）：个人计划创建时必须读取最近一次能力评估薄弱项并留存 `source_assessment_id` 快照（BR-007）；非竞赛会员创建个人补强计划返回 `400`。

### 2.2 竞赛域（莫姝负责，前缀 `/api/v1/contest`）

| 方法 | 路径 | 入参（JSON body） |
| :--- | :--- | :--- |
| GET | `/teams` | 查询参数 `season / status / keyword` |
| POST | `/teams` | `name, season, leader_member_id, member_ids[]` |
| GET | `/teams/recommend` | —（**路由须声明在 `/teams/{id}` 之前**） |
| GET | `/teams/{id}` | — |
| POST | `/teams/{id}/adjust` | `action, member_id, reason`（前端客户端已预留，UI 暂未接按钮） |
| GET | `/school-contests` | — |
| POST | `/school-contests` | `name, term, round` |
| GET | `/school-contests/{id}/entries` | — |
| POST | `/school-contests/{id}/entries` | `member_id, prelim_rank, prelim_score, status` |
| POST | `/school-contests/{id}/confirm` | `entry_id, confirmed, auto` |
| GET | `/school-contests/{id}/anomalies` | — |
| POST | `/school-contests/{id}/anomalies` | `member_id, evidence_url, description` |
| PUT | `/school-contests/{id}/anomalies/{anomaly_id}/review` | `review_conclusion, reviewer` |
| GET | `/non-xcpc` | — |
| POST | `/non-xcpc` | `name, category, member_id, award` |
| GET | `/xcpc` | — |
| POST | `/xcpc` | `name, team_id, site, rank, solved, penalty, award` |

**出参字段契约：**

- `Team`：`id / name / season / status / leader_member_id / members[] / adjust_logs[]`；`members[]` 里每个成员快照需含六维能力字段 `member_id / name / student_no / role / overall_score / lang_basic / basic_algo / simulation_logic / boundary_handling / knowledge_combo / coding_debug / weak_points[]`
- `Team.recommend` 候选组合：`id / name / complementarity_score / members[]（同上快照）/ suggestion`
- `SchoolContestEntry`：`id / contest_id / member_id / member_name / student_no / prelim_rank / prelim_score / status(REGISTERED|WAITLISTED|PROMOTED|CONFIRMED|ABANDONED) / auto / confirm_time`
- `Anomaly`：`id / contest_id / member_name / evidence_url / description / status(PENDING_REVIEW) / review_conclusion / reviewer / review_time`
- `XcpcResult`：`id / name / round / team_id / team_name / rank / solved / penalty / site / award`
- `NonXcpcResult`：`id / name / category / member_id / member_name / award / award_level`

> 关键业务约束：校赛个人制挂 `member_id`；放弃/逾期确认须同事务按 `prelim_rank` 升序自动递补候补（BR-009）；异常行为仅留存材料、状态固定 `PENDING_REVIEW`、人工写三值结论 `CONFIRMED_VIOLATION|EXONERATED|NEED_MORE_EVIDENCE`（BR-010）；XCPC/暑期集训必须 `team_id` 非空（BR-008）。
